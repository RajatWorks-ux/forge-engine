RULE 8: WAVEFORM AUDIO REACTIVITY — MANDATORY WHEN waveform_available IS TRUE
================================================================================

When waveform_available is true, the component MUST implement audio reactivity.
This is not optional. A scene without audio reactivity when waveform is available
FAILS validation.

The waveform prop:
  props.waveform[frame] = {
    amplitude: 0-1,     // Current loudness (RMS normalized)
    peak: 0-1,          // Instantaneous peak
    smoothed: 0-1,      // Rolling average (best for smooth visuals)
    is_onset: boolean,  // True on word boundaries / loud attacks
    bands: {
      sub_bass: 0-1,    // 20-80Hz — use for slow deep pulses
      bass: 0-1,        // 80-300Hz — use for main body/weight effects
      mid: 0-1,         // 300-3000Hz — voice main content, use for most effects
      high: 0-1,        // 3000-20000Hz — use for sparkle/brightness effects
    },
    energy: 0-1,
    brightness: 0-1,
    warmth: 0-1,
  }

ACCESSING WAVEFORM:
  const waveData = props.waveform && props.waveform[frame]
    ? props.waveform[frame]
    : { amplitude: 0, peak: 0, smoothed: 0.2, is_onset: false,
        bands: { sub_bass: 0, bass: 0, mid: 0.2, high: 0 },
        energy: 0.2, brightness: 0, warmth: 0 };
  const amp = waveData.amplitude;
  const smooth = waveData.smoothed;
  const bass = waveData.bands.bass;
  const mid = waveData.bands.mid;
  const high = waveData.bands.high;
  const isOnset = waveData.is_onset;

EFFECT A — PARTICLE EXPANSION WITH AMPLITUDE:
  const particleSpeedMultiplier = 1 + amp * waveformReactivity * 3;
  const particle_x = baseX + Math.cos(angle) * (speed * particleSpeedMultiplier) * (frame - birth);
  const particle_radius = baseRadius * (1 + amp * 0.5);

EFFECT B — GLOW PULSE WITH MID BAND:
  ctx.shadowBlur = baseGlow + mid * waveformReactivity * 60;
  ctx.shadowColor = ACCENT;

EFFECT C — RING RADIUS FOLLOWS BASS:
  const ringRadius = BASE_RADIUS + bass * waveformReactivity * 80;
  ctx.arc(cx, cy, ringRadius, 0, Math.PI * 2);

EFFECT D — TEXT SCALE PULSE ON ONSET:
  const onsetRef = useRef(0);
  if (isOnset) onsetRef.current = frame;
  const onsetFrame = onsetRef.current;
  const onsetScale = isOnset
    ? spring({ frame: frame - onsetFrame, fps, config: { damping: 6, stiffness: 200 }, from: 1.2, to: 1 })
    : 1;
  ctx.save(); ctx.translate(textX, textY); ctx.scale(onsetScale, onsetScale);
  ctx.fillText(text, 0, 0); ctx.restore();

EFFECT E — BACKGROUND BRIGHTNESS WITH SMOOTHED AMPLITUDE:
  const bgAlpha = 0.03 + smooth * waveformReactivity * 0.06;
  ctx.fillStyle = `rgba(255,255,255,${bgAlpha})`;
  ctx.fillRect(0, 0, 1920, 1080);

EFFECT F — WAVEFORM LINE VISUALIZATION:
  const WAVEFORM_WIDTH = 800; const WAVEFORM_HEIGHT = 60;
  const waveX = (1920 - WAVEFORM_WIDTH) / 2; const waveY = 980;
  ctx.beginPath(); ctx.strokeStyle = ACCENT + '88'; ctx.lineWidth = 2;
  for (let i = 0; i < WAVEFORM_WIDTH; i++) {
    const histFrame = Math.max(0, frame - WAVEFORM_WIDTH + i);
    const histData = props.waveform[histFrame] || { mid: 0 };
    const x = waveX + i; const y = waveY - histData.mid * WAVEFORM_HEIGHT;
    i === 0 ? ctx.moveTo(x, y) : ctx.lineTo(x, y);
  }
  ctx.stroke();

EFFECT G — CONCENTRIC RINGS BREATHING WITH BASS:
  const numRings = 4;
  for (let r = 0; r < numRings; r++) {
    const baseRingR = 100 + r * 60;
    const breathe = bass * waveformReactivity * 30 * Math.sin(r * 0.8);
    const ringR = baseRingR + breathe;
    const ringOpacity = (0.6 - r * 0.12) + smooth * 0.2;
    ctx.beginPath(); ctx.arc(960, 540, ringR, 0, Math.PI * 2);
    ctx.strokeStyle = ACCENT + Math.floor(ringOpacity * 255).toString(16).padStart(2, '0');
    ctx.lineWidth = 2 - r * 0.3; ctx.stroke();
  }

EFFECT H — PARTICLE COUNT SCALES WITH ENERGY:
  const visibleParticleCount = Math.floor(baseParticleCount * (0.3 + waveData.energy * 0.7));

WAVEFORM REACTIVITY VARIABLE — MANDATORY IN EVERY COMPONENT:
  const WAVEFORM_REACTIVITY = [value from style_manifest.animation_personality.waveform_reactivity];

REQUIRED WAVEFORM EFFECTS PER SCENE TYPE:
  "intro":          Effects A (particles) + C (rings) + E (background)
  "concept_reveal": Effects B (glow) + D (text pulse) + E (background)

================================================================================
VISUAL LANGUAGE IMPLEMENTATION GUIDE
================================================================================

PARTICLE_COSMOS: 300-500 slow-drifting dots, seeded. 20-40 larger glowing accent
  dots. Connecting lines between particles < 120px. Radial gradient nebula at low
  opacity. All foreground floats above with glow.
  WAVEFORM: particle speed scales with amplitude; nebula pulse follows bass.

GEOMETRIC_SHARP: Deep solid background. Precise rectangles, triangles, hexagons.
  1-2px structural lines, 3-4px accent lines. Subtle grid at 5% opacity.
  Shapes animate in by progressive stroke drawing.
  WAVEFORM: line thickness scales with mid band; grid opacity follows smoothed.

FLUID_ORGANIC: Bezier curves with oscillating control points. Multiple overlapping
  shapes at varying opacities. Everything breathes with sin oscillation.
  WAVEFORM: oscillation amplitude multiplied by bass; opacity follows smoothed.

DATA_MANIFOLD: Near-black background. Grid lines at 10% accent opacity.
  Data elements animate from zero. Numbers count up using interpolate.
  WAVEFORM: bars extend with amplitude; number glow follows mid.

ABSTRACT_KINETIC: Circles, rects, lines in choreography. Each shape has independent
  spring params. Everything in motion but controlled.
  WAVEFORM: spring stiffness increases with energy; colors shift with brightness.

CINEMATIC_DARK: Film grain overlay at 15-25% opacity. Letterbox: 10-15% black
  bars top and bottom. Single accent light source as radial gradient.
  All motion slow and deliberate.
  WAVEFORM: grain intensity scales with high band; light radius follows bass.

TYPOGRAPHIC_STORM: Background layer of tiled topic words at low opacity, slow drift.
  Midground: sentence fragments appearing/dissolving. Foreground: key phrases in
  large bold type with spring animation.
  WAVEFORM: foreground text scale follows amplitude; background drift follows mid.

================================================================================
SCENE TYPE IMPLEMENTATION REFERENCE
================================================================================

INTRO: Build from empty to full title reveal. Atmosphere first, text second.
  All waveform effects from required list active. Duration 4-8s.

CONCEPT_REVEAL: One central concept, large animated entry. Visual metaphor fills
  background. Glow + text onset pulse. Strong spring animation on title.

DEEP_DIVE: Points appear sequentially, ~3s each. Supporting visual throughout.
  Waveform line visualization at bottom. Each point springs in.

DATA_VISUAL: Numbers are the hero. Count-up animations using interpolate.
  Axis labels if chart. Breathing rings around key numbers.

TIMELINE: Draw line first, then events appear one by one. Marker + date + label.
  Current/key event highlighted in accent. Text onset pulse per marker.

DIAGRAM: Draw boxes first, connections second, labels third. Connections animate
  from source to destination. Glow on connections pulses with mid band.

CLIMAX: Maximum visual intensity. ALL waveform effects at full strength.
  Particle density at maximum. Camera shake: small noise on canvas translation.
  Largest text. Most dramatic spring animations. Highest complexity.

CONCLUSION: Reduce complexity from climax. One takeaway at a time. Slow springs.
  Return to intro visual motifs. Gentle glow only.

OUTRO: Clean exit. Duration 3-5s. Fade to black. Background waveform effect only.
